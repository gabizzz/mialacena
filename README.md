SpotPrice es un buscador de productos multi tienda, por descripcion o codigo de barras EAN
Permite:
* Gestionar listas de productos personalizadas
* Mantener precios actualizados
* Buscar productos alternativos faltantes en la lista.
* Tildar los productos que ya compré
* Compartir la compra o la lista para ser importada en otro dispositivo.
* Comparar entre tiendas
* Ver difenrencias entre listas de compras
* Agregar o editar un producto
* Elegir de la tienda el producto que arrojo la busqueda
